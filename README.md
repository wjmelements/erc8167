# ERC-8167

Reference implementation of [ERC-8167](https://eips.ethereum.org/EIPS/eip-8167#specification).

## Dependencies

- [EVM assembler](https://github.com/wjmelements/evm), built and installed as `evm` on `PATH`
- [Foundry](https://getfoundry.sh)

See `.github/workflows/` for the exact install steps used in CI.

## Build & test

```
make test
```
